# Установка демо Орды на один-два iPhone с Windows

Демо собирается отдельным workflow **Orda iOS demo**. В его артефакте `orda-ios-demo` находится `Orda-demo-unsigned.ipa`. Сборка предназначена для подписи собственным Apple Account через Sideloadly; она ещё не подписана и не устанавливается простым открытием IPA в Telegram или Files.

Вариант использует `--dart-define=ORDA_IOS_DEMO=true`: БД хранится в Library приложения, кэш — в его временной папке, ключ шифрования — в обычном Keychain приложения. App Groups для демо не используются, Share/Notification extensions исключены из архива. Алгоритм шифрования базы сохранён. Обычные сборки без флага используют прежний App Group. Проверка компиляции в CI не заменяет проверку на реальном iPhone.

Нужны Windows, iPhone с iOS 15 или новее, USB-кабель и собственный бесплатный Apple Account. Mac для этого способа установки не нужен. Apple ограничивает бесплатные профили сроком 7 дней; после этого необходима повторная подпись. Для пилота на десяти iPhone с push нужен Developer Program. [Правила Apple](https://developer.apple.com/help/account/basics/about-your-developer-account).

Порядок установки:

1. Скачать Sideloadly с [официального сайта](https://sideloadly.io/). На Windows он требует версии iTunes и iCloud, ссылки на которые приведены там; существующие установки Apple самостоятельно не удалять без проверки.
2. Скачать артефакт **orda-ios-demo** из успешного запуска **Orda iOS demo** в Actions и извлечь `Orda-demo-unsigned.ipa` из ZIP.
3. Подключить разблокированный iPhone по USB и подтвердить доверие компьютеру на телефоне.
4. Выбрать устройство в Sideloadly и загрузить IPA. Авторизоваться своим Apple Account лично; пароль и коды в чат не отправлять. Выполнить подпись и установку.
5. Если iOS требует доверия разработчику, подтвердить свой профиль в «Настройки → Основные → VPN и управление устройством». На iOS 16+ для этого метода требуется Developer Mode; включение выполняет владелец телефона.
6. Открыть Орду. Проверить вход, обмен сообщениями, повторный запуск и восстановление истории. Для второго телефона повторить установку в пределах лимитов Apple Account.

Требования к Windows, подписи и обновлению описаны в [официальном FAQ Sideloadly](https://sideloadly.io/faq). Загрузка IPA в Telegram лишь передаёт файл; подпись и установка выполняются отдельно.

Пуши upstream FluffyChat отключены. Демо пока предназначено для интерфейса и сообщений при работающем приложении. Работа входящих звонков и уведомлений при заблокированном телефоне не подтверждена и требует собственной инфраструктуры APNs/FCM и доработки VoIP-пушей. Наличие CallKit в исходниках само по себе не завершает эту работу. [PushKit/CallKit Apple](https://developer.apple.com/documentation/pushkit/responding-to-voip-notifications-from-pushkit).
