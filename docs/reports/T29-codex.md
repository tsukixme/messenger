# T29 — новый дизайн Tildes и APK

Дата: 2026-10-02. Ветка: `tildes-design`. PR: https://github.com/tsukixme/messenger/pull/4.

## Сделано

- Применён утверждённый владельцем стиль green-gold: основной цвет `#334420`, тёплая светлая и тёмная палитры, золотые акценты.
- Обновлены экран приветствия, форма входа, шапка списка чатов, кнопки, поля и скругления. Обработчики Matrix-входа и чатов сохранены.
- Создан собственный векторный знак Tildes: исходный SVG, виджет Flutter, legacy/adaptive/monochrome launcher Android. Старые изображения и сведения об авторах сохранены; новые ресурсы — AGPL-3.0-or-later.
- Фирменная палитра выбирается по умолчанию; ранее сохранённый цвет и явно выбранные системные цвета сохраняются. Настройка `colorSchemeSeedInt` продолжает поддерживаться. Старое отсутствие сохранённого цвета теперь означает палитру бренда; оно не позволяло отличить явный выбор системного цвета от первого запуска.
- Номер сборки увеличен до `3569`, версия приложения `2.10.0`, ID `kz.tildes.chat`.

## Проблемы

- Локальный запуск Flutter-тестов на Windows ограничен существующей ошибкой native hook webcrypto/CMake (Ninja/x64). Тесты проверяются в Linux CI.
- Подпись APK использует ранее согласованный владельцем временный release-ключ на каждый запуск, архитектура arm64. Установка поверх прежнего APK с другим ключом может потребовать удаления приложения. Постоянный release-ключ — отдельное решение владельца.
- Проверка на физических телефонах ещё не выполнена. Иконки iOS/web launcher не заменяются в этой задаче APK.
- ВМ запущена, но 2026-10-02 при дополнительной проверке недоступна по SSH; ngrok вернул ERR_NGROK_3200, консоль Ubuntu показывает CPU soft lockup. Восстановление сервера ведётся отдельно от дизайна.
