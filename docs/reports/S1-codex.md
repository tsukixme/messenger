## Вывод проверки

- `VBoxManage showvminfo Ubuntu-Server-24.04 --machinereadable`:
  `VMState="running"`, память 4096 МБ, 4 CPU, сетевой адаптер 1 — bridge,
  кабель подключён. Режим сети не изменён.
- `VBoxManage guestproperty get` для
  `/VirtualBox/GuestInfo/Net/0/V4/IP`, `/VirtualBox/GuestInfo/Net/1/V4/IP`
  и `/VirtualBox/GuestInfo/OS/Release`: `No value set!`.
  Guest properties не являются достаточной проверкой сети установщика.
- `VBoxManage controlvm Ubuntu-Server-24.04 screenshotpng` и просмотр
  окна VirtualBox: установщик показывает `Keyboard configuration`,
  `Layout: Russian`, `Variant: Russian`. Установка ещё не завершена.
  Снимок сохранён только локально вне репозитория.
- Два управляющих ввода (`click` в поле раскладки и `Shift+Tab`) не
  изменили отображаемый экран; повторное автоматическое управление
  остановлено. Сообщений об ошибке от инструмента не было, но изменение
  состояния не подтверждено.
- `git status --short` до добавления документации: чисто.
- SSH без пароля: НЕ ПРОВЕРЕНО. `docker run hello-world`: НЕ ПРОВЕРЕНО.

## Проблемы

- Этап S1 не соответствует критерию готовности: Ubuntu пока находится
  в установщике; доступ SSH и работа Docker не установлены и не проверены.
- Требуется ручной выбор раскладки владельцем. Пароль Ubuntu владелец
  позднее придумывает и вводит сам; в чат его присылать нельзя.
- IP в гостевой системе пока неизвестен. Переключение на NAT разрешено
  инструкцией владельца при подтверждённой проблеме bridge, но отсутствие
  guest properties само по себе не является таким подтверждением.
