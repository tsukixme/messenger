## Проблемы

- Этап S1 не соответствует критерию готовности: загрузку Ubuntu подтвердил
  владелец; доступ SSH по ключу не проверен. Docker теперь подтверждён
  самостоятельной сборкой и запуском тестового auth-контейнера.
  Наличие OpenSSH в установочных логах не доказывает
  доступность работающего SSH-сервера.
- Владелец продолжает установку сам, Codex даёт инструкции по одному шагу.
  Пароль Ubuntu владелец придумывает и вводит сам; в чат его присылать нельзя.
- IP сообщён владельцем, но доступность с Windows не проверена.
  Переключение на NAT разрешено
  инструкцией владельца при подтверждённой проблеме bridge, но отсутствие
  guest properties само по себе не является таким подтверждением.
