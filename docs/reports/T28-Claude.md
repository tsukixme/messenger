### 4. Windows-ошибки из отчёта S4

Причины установлены по тексту ошибок; прогона не было, это не гарантии.

- **`FormatException: Unexpected extension byte` на `where.exe wasm-pack`.** Наиболее вероятная причина: `wasm-pack` на этом компьютере не установлен. Тогда `where.exe` печатает сообщение «не удаётся найти файлы» на русском в кодировке консоли (OEM), а Dart декодирует вывод как UTF-8 и падает. То есть ошибка кодировки вторична, первична отсутствующая программа. Проверка без изменений: в PowerShell `where.exe wasm-pack` (если выводит русский текст о ненайденном файле, гипотеза верна) и `chcp` (ожидается 866). Варианты: установить `wasm-pack` в проектное окружение Rust (после этого `where.exe` выдаёт путь латиницей), либо не использовать Windows для этой сборки вовсе.
- **`flutter test`: «Generator Ninja does not support platform specification, but platform x64», `CMAKE_C_COMPILER not set`.** Это следствие отсутствия Visual Studio C++ (`flutter doctor` это подтвердил): нативной зависимости `webcrypto` нечем собираться. Исправление локально: установка Visual Studio Build Tools, рабочая нагрузка «Desktop development with C++» (несколько ГБ, согласие с лицензией; решение владельца). Альтернатива без установки: гонять `flutter test` в Ubuntu CI.
- **Рекомендация:** не тратить время на Windows. `flutter analyze` на Windows работает (чисто до и после правки), а web, APK и тесты выполнять в Ubuntu CI. Повтор локальной подготовки web не рекомендуется, а при желании владельца требует отдельного разрешения (две попытки уже исчерпаны).
