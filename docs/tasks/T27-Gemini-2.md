# Задача T27 для Gemini 2

## Контекст

Задача для Antigravity 2.0, роль Gemini 2; отдельный аккаунт от Antigravity IDE / Gemini 1.
Tildes: приложение https://github.com/tsukixme/messenger, сервер https://github.com/tsukixme/messenger-server.
T23 возвращён на доработку: https://github.com/tsukixme/messenger/blob/main/docs/reports/T23-codex-review.md. Исходный ответ: https://github.com/tsukixme/messenger/blob/main/docs/reports/T23-Gemini-2.md.
ВМ управляет владелец, репозиториями — Codex. Сервер, домен и устройства для тестирования не переданы; iOS-путь не выбран. Нужен только исправленный текст инструкций, чек-листов и черновиков.

## Что сделать

1. Прочитай исходную карточку https://github.com/tsukixme/messenger/blob/main/docs/tasks/T23-Gemini-2.md и проверку Codex. Верни полный исправленный отчёт, перечень изменений, проверенный commit SHA, конкретные официальные ссылки и дату проверки.
2. Исправь ngrok по https://ngrok.com/docs/pricing-limits/free-plan-limits: лимиты агентов/endpoints, назначенный dev domain, квоты и предупреждение/cookie. Названия полей кабинета подтверждай источником; недоступный интерфейс не угадывай. Проверку заголовков curl отдели от проверки тела ответа; для Windows укажи curl.exe. В будущей публичной проверке health ожидается DEV_MODE=false. Команды подготовь для владельца, сейчас не выполняй.
3. Перепроверь условия WhatsApp: тестовые адресаты и входящие сообщения, Development/Live, необходимость business verification/юрлица/карты, подключение номера и доступность в Казахстане. Для каждого условия укажи источник, дату, применимость к конкретному способу подключения. Не объявляй непроверенное обязательным блокером; при недоступности Meta фиксируй ограничение.
4. Перепроверь актуальную оплату: сообщения и их категории, сервисное окно, квоты и даты вступления изменений. https://whatsappbusiness.com/products/platform-pricing/ доступна; подробная Meta pricing при проверке Codex ответила 429. Не обещай ни старые «1000 conversations», ни безлимитную бесплатность. Платные/неизвестные сценарии оставь для решения владельца.
5. Исправь API: auth возвращает `user_id` и `password`, затем клиент получает Matrix-токен отдельным login. Для Android, Safari/web и iOS-приложения подготовь полные отдельные чек-листы: мобильная сеть, предупреждение, health/versions, успешный и повторный вход, неверный код/чужой номер, TTL, обмен сообщениями, перезапуски клиента/сервера, отсутствие сети. Незапущенное — «не проверено»; версия Matrix оценивается по фактическому JSON.
6. Отдели варианты iOS, их стоимость и условия по Apple: https://developer.apple.com/programs/. TestFlight не является вариантом без членства; Ad Hoc и Enterprise не смешивать. Выбор оставить владельцу, платные услуги не подключать.
7. Во всех доказательствах требуй маскировать номера, sid, коды, пароли и access tokens. Verify Token владелец выбирает случайно локально; в примере только ***. Уточни черновики текстов: телефон в Matrix ID/профиле и логах, память попыток/сессий и lazy-очистка, Meta/ngrok, неподтверждённые сроки удаления. Не утверждай уже работающее развёртывание или полную защищённость.
8. Убери указание немедленно запускать `docker compose up -d`: S1 ещё не принят, публичный auth имеет подтверждённый риск. Действия следующих этапов обозначь будущими, после готовности и отдельного «дальше» владельца. Один простой шаг на действие.

## Готово, когда

- Все замечания устранены во всём отчёте; факты имеют точные источники, неизвестное явно отмечено.
- Все три чек-листа полны, содержат результат/доказательство/статус и правило маскировки секретов.
- Бесплатность, iOS и условия Meta представлены без неподтверждённых обещаний; решения остаются владельцу.
- Исправленный ответ пригоден для `docs/reports/T27-Gemini-2.md`; реальные тесты не объявлены выполненными.

## Нельзя

- Не проси и не пиши секреты или реальные номера; секреты — `***`.
- Не трогай ВМ, чужие проекты, общую папку и репозитории; GitHub только для чтения. Не делай commit/push/merge и не запускай проверки на реальном сервере/устройствах.
- Не создавай аккаунты, не входи за владельца, не принимай согласия, не оплачивай услуги и не выбирай архитектуру/iOS. Работай только с публичными источниками и текстом ответа.
